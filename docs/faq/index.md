## 课程与学习方法 { #faq-1 }

??? question "网络版和纸质教材有什么不同？"

    章节结构和节号与纸质教材基本一致。网络版逐条核对了书中的事实、数据和引文，发现的错误和已经过时的信息直接在正文中改正，改了哪些见[网络版与纸质版对照](../errata.md)。网络版还增加了每节的“学前导读”、28 个交互动画、随堂小测、19 个在线体验，章末课后练习是重新编写的。

??? question "我不是理工科专业，数学也不好，能学好吗？"

    能。本课程面向所有专业，正文不要求数学和编程。少量公式和代码都放在“深入一步（选学）”折叠框里，跳过不影响理解后面的内容。抽象的原理（如神经网络怎样学习、扩散模型怎样画图）都有交互动画，拖一拖、点一点就能看明白。

??? question "每一节应该怎么学？"

    建议按“学前导读 → 正文和动画 → 随堂小测”的顺序：先读学前导读，知道本节要解决什么问题、哪些内容只需了解；读正文时把嵌入的动画亲手操作一遍；最后做随堂小测检查自己。每章的“本章怎么学”表格给出了各页的建议用时。

??? question "书里的 AI 产品名称和我手机上看到的不一样，怎么办？"

    AI 产品更新很快，名字、版本和功能经常变化。正文只讲原理和用法，具体产品集中放在[工具快照](../tool-snapshot.md)页，每学期更新一次。界面不一致时，以产品当前界面为准，按正文讲的思路找对应功能即可。

## 概念辨析 { #faq-2 }

??? question "人工智能、机器学习、深度学习、大模型是什么关系？"

    一层套一层：人工智能是最大的范畴，指让机器完成需要人类智能的任务；机器学习是实现人工智能的一类方法，让机器从数据中学规律；深度学习是机器学习中使用多层神经网络的方法；大模型是用深度学习在海量数据上训练出来的超大规模模型。见 [1.2 节](../chapters/01-ai-intro/1-2.md#12)和[第 2 章](../chapters/02-ml-logic/index.md)。

??? question "大模型真的“理解”我说的话吗？"

    这是一个仍有争议的问题。大模型通过预测下一个词元学会了语言的统计规律，能给出流畅、常常正确的回答，但它也会一本正经地编造事实（幻觉），有时在简单问题上犯人不会犯的错。“中文房间”思想实验讨论的正是这个问题，见 [1.1.1 节](../chapters/01-ai-intro/1-1.md#111)和 [3.8.1 节](../chapters/03-language/3-8.md#381)。实用的态度是：把它当作能力很强、但需要核实的助手。

??? question "为什么同一个问题问两遍，AI 的回答不一样？"

    大模型每次是按概率“抽”下一个词元的，温度越高，抽到不常见词的机会越大，回答就越多样。所以同一个问题可能得到不同的回答。可以在[温度与采样](../sims/temperature-sampling/index.md)动画里亲手试试，原理见 [3.3.1 节](../chapters/03-language/3-3.md#331)。

??? question "“深度思考”模式是什么？什么时候该打开？"

    打开后，模型会先写出一段推理过程，边想边检查，再给出答案，类似人的“慢思考”。数学题、逻辑题、需要多步分析的问题适合打开；查个常识、改个错别字就没必要，既慢又费词元。见 [2.2 节](../chapters/02-ml-logic/2-2.md#221)和[快思考与慢思考](../sims/fast-slow-thinking/index.md)动画。

??? question "智能体和普通的聊天机器人有什么区别？"

    聊天机器人主要是“你问它答”；智能体能自己拆解任务、调用工具（搜索、计算器、日历、数据库等）、根据结果调整下一步，直到把事情办完。见 [5.1.2 节](../chapters/05-agents/5-1.md#512)。

## 使用 AI 学习与写作 { #faq-3 }

??? question "可以用 AI 写作业吗？"

    先看学校和课程的规定，不同课程的要求可能不同。一般来说，用 AI 解释概念、出题考自己、检查语法和逻辑漏洞是好的用法；让 AI 代写、再署上自己的名字交上去，属于学术不端。使用了 AI 的，要如实说明在哪些环节用了。体验 8-2 会带你制定一份自己的 [AI 学习使用公约](../chapters/08-ethics/labs.md#8-2)。

??? question "AI 给出的资料和参考文献可以直接用吗？"

    不可以直接用。大模型会编造看起来很真实的论文、数据和法条（幻觉）。凡是要引用的事实、数据和文献，都要到原始出处核对；用带出处的 AI 搜索或 RAG 知识库能减少幻觉，但也要点开来源看。见 [1.7.1 节](../chapters/01-ai-intro/1-7.md#171)和 [3.6.1 节](../chapters/03-language/3-6.md#361)。

??? question "怎样让 AI 的回答更有用？"

    把话说清楚：交代背景、说明目标、指定风格和语气、说明给谁看、规定输出格式，这就是 CO-STAR 法则（[3.5.1 节](../chapters/03-language/3-5.md#351)）。复杂任务可以给几个例子（少样本提示），或者让它一步一步想。[提示词改写前后](../sims/prompt-rewrite/index.md)动画演示了每个要素的作用。

??? question "AI 生成的图片可以随便用吗？有没有版权？"

    要分情况。我国法院认为，如果使用者在构思、提示词设计、参数调整和挑选中体现了独创性的智力投入，生成的图片可以构成作品；拿不出创作过程证据的，也可能不被认定。使用时还要注意不能侵犯他人的肖像、商标和作品，并按规定保留 AI 生成标识。见 [8.1 节](../chapters/08-ethics/8-1.md#812)和[附录 A](../appendix/a-laws.md)。

## 安全与隐私 { #faq-4 }

??? question "接到熟人视频电话借钱，怎样判断是不是 AI 换脸？"

    最可靠的办法不是看画面，而是**换一个渠道核实**：挂断后用你自己存的电话号码打回去，或者问一个只有你们两人知道的问题。也可以让对方在镜头前转头、用手在脸前晃一晃，换脸画面容易出现破绽，但新技术越来越难看出来。涉及转账，一律先核实。见 [7.1.4 节](../chapters/07-safety/7-1.md#714)。

??? question "哪些信息不要发给 AI？"

    身份证号、银行卡号、密码、验证码、病历、家庭住址等个人敏感信息，以及单位未公开的资料、合同、代码，都不要输入 AI 工具。你输入的内容可能被保存、被用于改进模型，也可能因为漏洞泄露。见 [7.3 节](../chapters/07-safety/7-3.md#731)和[体验 7-2](../chapters/07-safety/labs.md#7-2)。

??? question "什么是提示词注入？和我有关系吗？"

    提示词注入是把恶意指令藏在输入或网页、文档里，诱导 AI 违背原来的设定，例如泄露机密、乱发邮件。当你让 AI 助手帮你读网页、处理邮件时，网页和邮件里藏着的指令也可能“劫持”它。所以给 AI 助手授权要谨慎，重要操作要人来确认。见 [7.2.1 节](../chapters/07-safety/7-2.md#721)和[AI 防火墙攻防](../sims/ai-firewall/index.md)动画。

## AI 与未来 { #faq-5 }

??? question "AI 会取代我的工作吗？"

    AI 更可能先改变工作中的一部分任务，而不是整个职业。重复、有固定规则的任务最容易被替代；需要判断、沟通、创造和承担责任的部分仍然要靠人。最有竞争力的是会和 AI 配合的人，即“半人马模式”。见 [8.3.3 节](../chapters/08-ethics/8-3.md#833)和 [6.5 节](../chapters/06-ai-plus-x/6-5.md#651)。

??? question "非 AI 专业的学生，学这门课有什么用？"

    几乎每个行业都在用 AI 改造流程。第 6 章的三层融合模型和“AI+X 架构师”方法，能帮你看清 AI 在自己专业里能做什么、不能做什么，体验 6-1 会带你为自己的专业做一个小原型。会提问、会核实、会协作、守底线，这四种能力在任何岗位上都有用。

??? question "学完这门课，还想深入学 AI，可以学什么？"

    想继续了解原理，可以读各章末尾的拓展阅读（汇总在[附录 B](../appendix/b-references.md)）；想动手开发，可以从 Python 编程入门，再学机器学习和深度学习；不想写代码，可以深入学习提示词工程和扣子、Dify 等零代码平台，用 AI 解决本专业的实际问题。
