# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [人工智能发展时间线](ai-timeline/index.md) | 沿时间轴浏览人工智能的三次浪潮和两次低谷，比较不同年代的 AI 怎样解决同一个问题 |
| 第 1 章 | [图灵测试小游戏](turing-test/index.md) | 读 10 组问答，判断哪一边是人、哪一边是 AI，体会图灵测试的做法和局限 |
| 第 2 章 | [动物识别专家系统](animal-expert/index.md) | 勾选观察到的特征，逐条触发规则完成正向推理，查看解释器的推理过程，自己添加规则 |
| 第 2 章 | [迷宫寻路：三种搜索比一比](maze-search/index.md) | 在同一个迷宫上运行广度优先、深度优先和 A* 搜索，比较展开的格子数和路线长度 |
| 第 2 章 | [井字棋对弈：极小极大](tic-tac-toe/index.md) | 和用极小极大算法下棋的计算机对弈，查看每个空格的评分，比较剪枝开关时检查的局面数 |
| 第 3 章 | [曲线拟合与过拟合](curve-fitting/index.md) | 拖动模型复杂度，看训练误差一路下降、测试误差先降后升 |
| 第 3 章 | [K 近邻与 K 均值](knn-kmeans/index.md) | 放一位新会员看 K 近邻怎样投票分类，再一步步看 K 均值怎样把会员分群 |
| 第 3 章 | [阈值与混淆矩阵](threshold-confusion/index.md) | 拖动阈值，观察混淆矩阵和准确率、精确率、召回率的实时变化 |
| 第 4 章 | [手写数字识别](digit-recognition/index.md) | 写一个数字，看训练好的神经网络怎样把它缩成 8 × 8 图像、经过隐藏层，给出 10 个数字的概率 |
| 第 4 章 | [梯度下降：蒙着眼睛下山](gradient-descent/index.md) | 拖动学习率，看小球怎样沿坡度一步步走向谷底，体会学习率太小、太大和局部最低点 |
| 第 4 章 | [神经元与激活函数](neuron-activation/index.md) | 调权重、换激活函数，看神经元的输出；让感知机学“异或”，亲眼看它学不会 |
| 第 5 章 | [自注意力热力图](self-attention/index.md) | 看句子里每个词在“注意”哪些词，体会“它”怎样找到它指代的对象，以及掩码的作用 |
| 第 5 章 | [温度与采样](temperature-sampling/index.md) | 调节温度、Top-k、Top-p，看语言模型给出的下一个字的概率怎样变化，抽一抽看实际选出的字 |
| 第 5 章 | [词向量与余弦相似度](word-vectors/index.md) | 拖动向量体会“只看方向不看长短”，在词语地图上找近义词、做类比 |
| 第 6 章 | [卷积滤镜](conv-filter/index.md) | 选卷积核处理图片，点任意像素看 3 × 3 窗口的计算过程，体会模糊、锐化和边缘检测 |
| 第 7 章 | [声音的模样：波形与频谱](sound-spectrum/index.md) | 对比纯音、口哨、元音、和弦、噪音的波形和频谱，用麦克风看自己的声音，调采样率和量化位数看数字化的效果 |
| 第 8 章 | [Q 学习格子世界](q-learning/index.md) | 看机器人用 Q 学习从乱走到找到宝藏，调探索率、学习率、折扣和奖励，观察学习的快慢 |
| 第 8 章 | [智能体工作过程回放](react-replay/index.md) | 回放智能体“思考—行动—观察”的全过程，同时看到程序和大模型之间实际传递的消息 |
| 第 9 章 | [信息茧房模拟](filter-bubble/index.md) | 点开喜欢的内容，看推荐系统怎样越来越“懂”你、推荐种类怎样越来越少，再试试打破信息茧房的四种办法 |
