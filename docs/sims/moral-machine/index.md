## 教学说明

**学习目标**

1. 能说出自动驾驶伦理中常见的几种取舍因素（记忆）；
2. 能对照自己的选择和德国伦理准则，说明“按个人特征区别对待”为什么有争议（分析）；
3. 能讨论“多数人的偏好”能否直接变成机器的规则（评价）。

**画面与操作**

- 每个情境点 A 或 B 选一个方向，上方进度条显示进度。
- 8 题做完后显示你在 7 个因素上的倾向，以及“道德机器”实验的全球总体倾向。
- 点“再来一次”可以重做。

**数据说明**：情境参照 2018 年《自然》杂志发表的“道德机器”实验设计；全球倾向是对论文结论的定性概括。结果只反映选择倾向，不代表道德水平。

**课堂用法建议**

1. 先独立做，再分组比较结果差异最大的情境。
2. 讨论：谁应该为这些规则负责？现实中的自动驾驶首先要避免陷入两难。
