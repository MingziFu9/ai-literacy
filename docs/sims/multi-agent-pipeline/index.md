## 教学说明

**学习目标**

1. 能说出顺序流、层级式、圆桌讨论三种协作模式的特点（理解）；
2. 能说明“审稿智能体”这类检查环节的作用（理解）；
3. 能为一个具体任务选择合适的协作模式（应用）。

**画面与操作**

- 上方选协作模式，可打开或关闭审稿智能体。
- 点“下一步”或“自动播放”，看消息记录、流程图中的高亮和当前稿件的变化。
- 初稿里藏着 3 处错误，对照右下的活动资料，看哪些被拦下、哪些漏到了最终稿。

**数据说明**：智能体的发言是编者编写的示意，不是真实系统的运行记录。

**课堂用法建议**

1. 先关掉审稿智能体跑一遍，再打开跑一遍，比较最终稿的错误数。
2. 讨论：人在这条流水线上应该放在哪个位置？
