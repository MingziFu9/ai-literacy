## 教学说明

**学习目标**

1. 能解释“删掉敏感属性”为什么不能消除偏见（理解）；
2. 能用分组录用率和混淆矩阵检查模型是否公平（应用）；
3. 能比较几种改进办法的效果和代价（评价）。

**画面与操作**

- 上方按顺序点 5 个步骤按钮。
- 第 2 步看男女录用率差距，第 3 步看“名校”这个代理变量，第 4 步比较两组的混淆矩阵。
- 第 5 步表格比较原模型、去掉院校、分组门槛、修正标签四种办法。

**数据说明**：1000 位应聘者是用固定随机种子生成的模拟数据，模型是用梯度下降训练的逻辑回归，思路与 8.6.1 节“深入一步”的 Python 代码相同，数值略有差别。

**课堂用法建议**

1. 每一步先让学生预测结果，再点开验证。
2. 第 5 步讨论：你会选哪种办法？为什么？
