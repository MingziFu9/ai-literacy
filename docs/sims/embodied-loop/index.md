## 教学说明

**学习目标**

1. 能说出具身智能中感知—决策—行动的闭环（理解）；
2. 能说明大脑、小脑、脊髓三层控制各管什么（理解）；
3. 能解释力反馈为什么对抓取易碎物品很重要（理解）。

**画面与操作**

- 选一条指令（拿水杯或拿鸡蛋），点“开始执行”。
- 看三层面板依次工作：大脑拆解任务，小脑在地图上找路线，脊髓调节握力。
- 点房间空地放置障碍物，看路线怎样改变；关掉力反馈再拿鸡蛋，看看会怎样。

**数据说明**：大脑的任务拆解是预先写好的；小脑用广度优先搜索找最短路线；脊髓用简单的比例反馈控制握力。真实机器人每一层都复杂得多。

**课堂用法建议**

1. 让学生堵住路线，讨论“规划”和“执行”为什么要分开。
2. 联系 5.4 节讨论：大模型能当机器人的哪一层？
