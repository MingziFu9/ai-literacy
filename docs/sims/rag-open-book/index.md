## 教学说明

**学习目标**

1. 能说出 RAG 的三步：检索、拼接、生成（理解）；
2. 能解释 RAG 为什么能减少幻觉、回答私有和最新的信息（理解）；
3. 能说明资料库缺失或检索不准时 RAG 也会答错（分析）。

**画面与操作**

- 选一个问题（或自己输入），点“提问”。
- ① 闭卷：模型只凭记忆回答，常常编造。② 检索：问题与每段资料的相似度，前 3 名高亮。③ 开卷：根据检索到的资料回答，并注明出处。
- 在资料库里取消勾选某段资料，再提问，看检索和回答怎样出错。

**数据说明**：资料库是虚构的《××职业技术学院学生手册》8 段节选；相似度用“两个字一组”的余弦相似度计算，真实系统用嵌入模型。

**课堂用法建议**

1. 先问“补考怎么申请”，再删掉相关段落重问，讨论“资料库的质量决定回答的质量”。
2. 联系学生自己的学校手册，讨论哪些场景适合做 RAG 问答。
