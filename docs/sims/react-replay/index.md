## 教学说明

**学习目标**

1. 能说出 ReAct“思考、行动、观察”三个步骤各做什么（记忆）；
2. 能从回放中指出智能体在什么时候调用了什么工具、为什么（理解）；
3. 能说明智能体根据观察结果调整做法的好处（分析）。

**画面与操作**

- 上方选择三个问题：今天星期几、图书馆几点关门；奖学金加起来多少钱；挂科了怎么办。下面列出智能体可以使用的三个工具。
- 点“下一步”逐步回放，“自动播放”连续播放，“重来”从头开始。
- 左边是思考链（思考、行动、观察、回答），右边是程序和大模型之间实际传递的消息（对话历史），下方是这一题的要点。

**数据来源**：三个问题的回放是编者按真实智能体的运行方式编写的示意过程，工具返回的内容来自一份虚构的“星海职业学院学生手册”。本动画与《自然语言处理导论》共用，该书第 11 章有完整的实现代码。

**课堂用法建议**

1. 回放第二题，请学生说出“为什么金额要先检索、加法要用计算器”，联系第 5 章的幻觉。
2. 回放第三题，讨论第一次没查到时智能体是怎样调整的，再请学生设想：如果它一直查不到，程序应该怎么办？
