## 教学说明

**学习目标**

1. 能说出感知机就是“画一条直线来分类”（理解）；
2. 能解释单层感知机为什么解决不了异或问题（理解）；
3. 能说明多加一层（两条直线）为什么能解决，从而理解联结主义复兴的意义（理解）。

**画面与操作**

- 上方选“与 / 或 / 异或”三种任务，坐标图中橙色实心点要输出 1，空心点要输出 0。
- 拖动 w₁、w₂、b 三个滑块移动直线，右侧真值表实时显示每个点是否分对。
- 点“让感知机自己学”，看它按学习规则一步步挪直线。与、或很快学会；异或学 40 轮仍然失败，随后出现“两条直线”模式和“示范一组解”按钮。

**数据说明**：4 个点是逻辑运算的标准真值表；学习规则是经典感知机规则，学习率和轮数由编者设定。

**课堂用法建议**

1. 先让学生自己拖滑块分开“或”，再挑战“异或”，体会“怎么都分不开”。
2. 结合 1.2.2 节讲 1969 年明斯基对感知机的批评和 1986 年反向传播让多层网络可训练的转折。
