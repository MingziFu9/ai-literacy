## 教学说明

**学习目标**

1. 能说出 CO-STAR 六个要素分别是什么（记忆）；
2. 能说明缺少某个要素时输出容易出现的问题（理解）；
3. 能把一句“小白提示词”改写成结构完整的提示词（应用）。

**画面与操作**

- 上方选一个场景（社团招新、提醒老师的邮件、催款邮件）。
- 左边勾选背景、目标、风格、语气、受众、格式六个要素，提示词随之变长；右边的模拟输出随之变化。
- 下方检查清单逐项显示输出是否达标。“全部取消”回到小白写法，“全部勾选”看完整效果。

**数据说明**：输出是编者按规则拼接的示意，不是真实大模型的回答。

**课堂用法建议**

1. 每次只勾一个要素，让学生说出输出哪里变了。
2. 之后让学生用真实的国产大模型做体验 3-1，对比模拟和真实结果。
