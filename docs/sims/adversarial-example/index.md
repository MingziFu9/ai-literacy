## 教学说明

**学习目标**

1. 能说出什么是对抗样本（记忆）；
2. 能解释“精心计算”的噪声为什么比随机噪声更有效（理解）；
3. 能举例说明对抗样本在自动驾驶、人脸识别中的风险（应用）。

**画面与操作**

- 拖动扰动强度 ε 滑块，看原图、噪声（放大 5 倍显示）和加噪后的图。
- 下方条形图显示模型判断为“3”和“8”的概率。
- 切换“对抗噪声 / 随机噪声”，比较同样强度下模型的反应。

**数据说明**：分类器是一个简化的线性模型（把图片和“3”“8”两个模板比较）；对抗噪声用快速梯度符号法（FGSM）计算。ε 约 0.03～0.04 时模型就会改判。

**课堂用法建议**

1. 让学生找出模型刚好被骗的 ε，再问：人眼能看出变化吗？
2. 讨论：在停车标志上贴几张小贴纸，为什么也可能骗过自动驾驶？
