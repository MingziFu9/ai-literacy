# 网络版与纸质版对照

网络版以纸质教材《人工智能通识教程》（吴迪、龚志武主编，东南大学出版社，2026 年 5 月第 1 版）为底本，章节结构和节号与纸质版基本一致。人工智能发展很快，纸质教材付印后不少产品、政策和数据已经变化；编写网络版时，编者逐条核对了书中的事实、数据和引文，发现的问题已在网络版正文中直接改正。下表逐条列出，供教师备课和纸质教材重印时参考。

此外，网络版的随堂小测和章末课后练习是重新编写的，与纸质版的“思考与练习”不同；第 8 章的图号按网络版的插图顺序重新编排。
