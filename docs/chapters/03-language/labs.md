## 体验 3-1 提示词改写前后对比 {#3-1}

**体验目的**：用 CO-STAR 框架改写提示词，亲眼看到输出质量的变化。

**步骤**

1. 先打开 3.5.1 节的动画，或[全屏打开“提示词改写前后”](../../sims/prompt-rewrite/main.html){ target=_blank }，选一个场景，逐个勾选六个要素，观察输出的变化。
2. 从下面三个任务中选一个，或者用你专业里的一个真实任务：
    - 给即将到来的社团招新写一段朋友圈文案；
    - 给一位迟迟没有回复邮件的老师写一封礼貌的提醒邮件；
    - 为本专业的新生写一份“第一学期学习建议”。
3. 先用一句话的“小白写法”提问，保存输出；
4. 再按 CO-STAR 六要素写一个完整的提示词，新建对话提问，保存输出；
5. 给两次输出各打 1～5 分，写下你认为差别最大的地方。

**记录表**

| | 提示词（摘要） | 输出评分 | 主要问题 / 优点 |
|---|---|---|---|
| 小白写法 | | | |
| CO-STAR 写法 | | | |

**想一想**：六个要素里，哪一个对输出质量影响最大？为什么？

## 体验 3-2 文档知识库问答 {#3-2}

**体验目的**：体会 RAG“开卷考试”的效果，学会核对 AI 给出的出处。

**步骤**

1. 准备一份你手头的长文档（20 页以上为宜），例如本校的学生手册、一份课程讲义、一篇论文的 PDF。不要用含个人隐私的文件。
2. 上传到一款支持文件的国产大模型，依次提问：
    - 一个文档开头就能找到答案的问题；
    - 一个答案在文档**中间**某页的细节问题（比如某条规定的具体天数、金额）；
    - 一个文档里**没有**答案的问题（比如问学生手册“学校食堂几点关门”，如果手册里没写的话）。
3. 每个问题都追问一句：“请给出原文出处（页码或章节）。”
4. 打开原文逐条核对。

**记录表**

| 问题 | AI 的回答 | 给出的出处 | 核对结果（对 / 错 / 编造） |
|---|---|---|---|
| 开头的问题 | | | |
| 中间的细节 | | | |
| 文档里没有的 | | | |

**想一想**

1. 对文档里没有答案的问题，AI 是老实说“没找到”，还是编了一个答案？
2. 把这个体验和第 1 章体验 1-2 的“本地信息”问题比较：有了文档，回答可靠了多少？

## 体验 3-3 两个模型盲评 {#3-3}

**体验目的**：学习排行榜“盲测投票”的方法，用自己的任务客观比较两个模型。

**步骤（两人一组）**

1. 同学甲准备 3 个任务，分别是写作、解题、建议类（例如：“用 200 字向初中生解释什么是大模型”“小明比小红大 3 岁，5 年后两人年龄和是 31 岁，小明今年几岁”“我下周要面试实习，请给我 5 条准备建议”）。
2. 同学甲把 3 个任务分别发给两款模型，把回答复制到文档里，**去掉模型名称**，标成“回答 A”“回答 B”（随机决定哪个是 A）。
3. 同学乙在不知道模型名称的情况下，逐题选出更好的回答，并写下理由。
4. 揭晓答案，统计每个模型“赢”了几题。交换角色再做一轮。

**想一想**

1. 你的盲评结果和第一印象（或网上的排行榜）一致吗？
2. 为什么排行榜要用“盲测”？如果事先知道是哪个模型，评分会受什么影响？
