# 3.1 语言智能的进化史诗 {#31}

!!! info "学前导读"

    让机器理解语言，人类走了三条路：先教它**规则**，再让它数**统计**，最后让它用**神经网络**自己学。本节沿着这条路线走一遍，重点体会词向量——“给词语定坐标”这个想法有多巧妙。

人类探索机器语言智能的历程，就是一部从“教机器规则”到“让机器自己学概率”的认知革命史。

## 3.1.1 符号主义时代：规则的牢笼（1950s—1980s） {#311}

在计算机诞生初期，很多研究者认为：语言的本质是逻辑。只要把人类所有的语法规则写成代码，机器就能理解语言。

**1. 图灵测试（1950）与“模仿游戏”**

1950 年，阿兰·图灵提出了用文字对话来检验机器智能的“模仿游戏”，并预言到 2000 年前后，机器能让普通提问者在 5 分钟对话后的识别正确率不超过 70%（详见 1.1.1 节）。这为后世设定了语言智能的远大目标。但在此后几十年里，那些看起来“能聊”的程序大多只是靠技巧取巧。

**2. ELIZA 的“伪装艺术”（1966）**

1966 年，麻省理工学院的约瑟夫·魏泽鲍姆开发了最早的聊天机器人之一——ELIZA。它最有名的脚本是扮演“罗杰斯学派”的心理咨询师。这种学派的特点是：很少给建议，主要通过复述和反问来引导对话，这恰好让程序很容易“装懂”。

!!! example "案例 3-1：一场跨越半个世纪的对话"

    魏泽鲍姆 1966 年论文中记录的对话（节选，意译）：

    > 用户：男人都一个样。<br>
    > ELIZA：怎么说？<br>
    > 用户：他们总是拿这样那样的事来烦我们。<br>
    > ELIZA：你能举个具体的例子吗？<br>
    > 用户：嗯，是我男朋友让我来这儿的。<br>
    > ELIZA：你男朋友让你来这儿的。<br>
    > 用户：他说我大部分时间都很沮丧。<br>
    > ELIZA：听到你很沮丧，我很难过。<br>
    > ……<br>
    > 用户：我父亲。<br>
    > ELIZA：你的父亲。<br>
    > 用户：你在某些方面很像我父亲。<br>
    > ELIZA：你看出了什么相似之处？

    **揭秘**：乍一看，ELIZA 似乎真的在倾听。但实际上，它的程序里没有任何“理解”的逻辑，只有一份“脚本”：一组关键词（如“我”“父亲”“男朋友”），每个关键词配上几条“拆句—重组”规则。下面是用现代代码写的示意（不是原程序）：

    ```text
    规则 1：如果用户说“我很 X”，就回复“听到你很 X，我很难过。”
    规则 2：如果用户提到“父亲 / 母亲 / 男朋友”，就把话题引向家人。
    规则 3：什么都没匹配上，就回复“请继续说下去”或“这一点很有趣”。
    ```

**局限性**：ELIZA 是规则方法的经典代表，也暴露了它的天花板。它像鹦鹉一样能逼真地模仿人类的句式，但根本不知道“父亲”和“男朋友”背后复杂的情感。一旦遇到脚本里没有的词或复杂的隐喻，就会“露馅”。

## 3.1.2 统计主义时代：大数据的暴力美学（1990s—2012） {#312}

互联网带来了海量文本。IBM 语音识别专家弗雷德·贾里尼克（Fred Jelinek）有一句据传的名言：“每当我解雇一个语言学家，我的语音识别系统的准确率就会上升。”人们发现，不依赖语法规则，仅通过统计概率也能做好很多语言任务。

**1. N-gram 模型**

原理：根据前面几个词，预测下一个词的概率。例如，句子“今天天气很____”：

- 接“好”的概率：30%；
- 接“糟糕”的概率：20%；
- 接“恐龙”的概率：0.000 01%。

机器通过统计报纸、网页中词语前后搭配的频率，就能判断哪个句子更通顺，用于输入法联想、语音识别、机器翻译等。

**2. Word2Vec：给词语“定坐标”（2013）**

谷歌提出的 Word2Vec 是 NLP 历史上的里程碑。在此之前，电脑里的“苹果”和“梨”只是两个不同的编号（如 1001 和 1002），电脑不知道它们都是水果。

Word2Vec 把每个词映射成高维空间（如 300 维）中的一个向量，向量之间的距离代表语义的接近程度：经常出现在相似上下文里的词，坐标也相近。

**语义的数学奇迹**：最著名的例子是

$$\text{King} - \text{Man} + \text{Woman} \approx \text{Queen}$$

把“国王”的向量减去“男人”的向量，再加上“女人”的向量，算出来的位置最接近“女王”（计算时要把输入的这三个词本身排除在外）。这说明，机器仅仅通过统计词语出现的上下文，就在向量空间里形成了表示“性别”“地位”等含义的方向。这是从“数词频”走向“表示语义”的关键一步；但这种类比运算并不总是成立，也不等于机器像人一样“懂”了这些概念。

## 3.1.3 神经网络时代：RNN 的记忆瓶颈（2013—2017） {#313}

深度学习开始接管 NLP。循环神经网络（RNN）模拟人类的阅读顺序：从左到右，读一个词，记一个词。

**致命缺陷：长距离遗忘**。就像读到《红楼梦》第 80 回时，已经记不清第 3 回林黛玉进贾府时的细节。RNN 读到长文的末尾，开头的信息已经衰减殆尽。

2017 年，谷歌团队发表论文 *Attention Is All You Need*，提出了 Transformer，开启了大语言模型的时代（详见 2.3 节）。
