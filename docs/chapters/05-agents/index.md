# 第 5 章 从工具到伙伴：智能体（AI Agent）

!!! abstract "本章学时"
    5 学时（线上 4 + 线下 1）· 在线体验 3 个 · 交互动画 3 个

计算机科学家拉里·特斯勒（Larry Tesler）有一句常被引用的话：“人工智能就是那些还没有被做到的事情。”一旦某项能力被做到了，人们就把它归为普通软件。

今天，智能体（AI Agent）正在把大模型从“会说”推向“会做”。你只需告诉它“帮我规划一次周末短途旅行”，它就能自己查天气、比较路线、列出预算，最后交给你一份方案。本章带你看清智能体是怎样构成的，亲手用零代码平台搭一个，并了解当很多个智能体协作、当智能体有了“身体”时，会发生什么。

## 学习目标

**知识目标**

1. 了解智能体的技术演进（规则式 → 学习式 → 大模型驱动）；
2. 掌握智能体的“四大支柱”（大脑、规划、记忆、工具）和 ReAct 工作循环；
3. 了解多智能体的协作模式和具身智能的分层控制思路。

**技能目标**

1. 能用扣子（Coze）等零代码平台搭建一个带知识库和工具的智能体；
2. 能运用结构化提示词和抗幻觉设计约束智能体的行为；
3. 能用简单的测试检查智能体的效果和安全性。

**素养目标**

1. 建立“人机协同”的工作观，理解“人在回路”的监督价值；
2. 认识智能体自主行动可能带来的失控风险，明确人的责任边界。

## 课程思政

在新一轮科技革命与产业变革中，发展人工智能已上升为国家战略。设计智能体的初衷，不应只是追求效率，更应致力于增进民生福祉：从偏远山区的教育公平，到独居老人的智能陪伴，让 AI 变得“有温度”是每一位开发者的社会责任。希望同学们在掌握技术的同时，时常想一想：“我的智能体能帮普通人解决哪些实际困难？”

## 本章关键词

智能体（AI Agent）· 推理—行动循环（ReAct）· 函数调用（Function Calling）· 模型上下文协议（MCP）· 智能体技能（Agent Skill）· 智能体开发平台（Coze / Dify）· 多智能体系统（Multi-Agent System）· 具身智能（Embodied AI）
