## 体验 2-1 深度思考开关对比 {#2-1}

**体验目的**：亲眼看到“快思考”和“慢思考”的区别，理解推理模型为什么更擅长多步骤的问题，也看到它的代价（更慢、更长）。

**步骤**

1. 打开一款带“深度思考”开关的国产大模型，**关闭**深度思考，新建对话，依次输入下面 4 道题，记录回答和用时：
    - 题 1：“9.11 和 9.9 哪个大？”
    - 题 2：“一个笼子里有鸡和兔共 35 只，脚共 94 只，鸡和兔各几只？”
    - 题 3：“所有的玫瑰都是花，有些花很快就会凋谢。能否推出有些玫瑰很快就会凋谢？”
    - 题 4：“用一句话介绍你自己。”
2. 新建对话，**打开**深度思考，再问一遍这 4 道题。展开“思考过程”，读一读它是怎样一步步推的。
3. 在思考过程中找一找：有没有出现“等等”“让我再检查一下”“不对”这类自我纠正的话？
4. 填写对比表。

**对比表**

| 题目 | 关闭深度思考：答案 / 对错 / 用时 | 打开深度思考：答案 / 对错 / 用时 | 思考过程里有没有自我纠正 |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

**想一想**

1. 哪些题打开深度思考后明显变好了？哪些题没有必要打开？
2. 深度思考会消耗更多的时间和算力。日常使用时，你会在什么情况下打开它？
3. 思考过程写得头头是道，就一定说明答案是对的吗？

## 体验 2-2 识图找错 {#2-2}

**体验目的**：体会卷积神经网络和多模态大模型“看图”的能力和局限。

**步骤**

1. 准备 4 张照片（自己拍，不要拍他人的脸）：一张常见物品（如水杯）、一张光线很暗或很模糊的物品、一张有文字的照片（如课程表）、一张容易让人误会的照片（如从奇怪角度拍的物品、两个东西叠在一起）。
2. 依次上传给一款能识图的国产大模型，问：“这张图里有什么？请尽量详细地描述。”
3. 对照照片逐条核对它的描述，标出说对的和说错（或编造）的地方。
4. 对说错的照片追问一句提示（如“你再看看左下角”），看它能否改正。

**记录表**

| 照片 | AI 的描述（摘要） | 说对了什么 | 说错 / 编造了什么 | 追问后是否改正 |
|---|---|---|---|---|
| 常见物品 | | | | |
| 暗 / 模糊 | | | | |
| 有文字 | | | | |
| 容易误会 | | | | |

**想一想**

1. AI 在哪种照片上最容易出错？结合 2.1.1 节“从边缘到整体”的层级特征想一想原因。
2. 如果把这样的识图功能用在医疗影像或安防监控上，出错的代价是什么？应该怎样设计“人机配合”？
