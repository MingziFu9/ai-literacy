# 3.1 语言智能的进化史诗

## 三个时代

| 时代 | 方法 | 代表 | 局限 |
|---|---|---|---|
| 符号主义 | 人写规则 | ELIZA（1966） | 规则写不完 |
| 统计主义 | 数词语共现的次数 | N-gram、Word2Vec | 看不懂长句 |
| 神经网络 | 从数据中学表示 | RNN → Transformer | 需要海量数据和算力 |

## 动画：词向量

!sim word-vectors
- 把词变成一串数字，意思相近的词方向相近
- 找近义词，做类比：国王 − 男人 + 女人 ≈ 女王
- 想一想：“苹果”离水果近，还是离手机近？

# 3.2～3.3 Transformer 与大模型的养成

## Transformer：鸡尾酒会上的注意力

![图 3-1 Transformer 架构图：Encoder-Decoder 及其内部组件](images/fig3-1.jpg)
- 嘈杂的聚会里，你能听清叫你名字的人
- 自注意力：每个词都去“听”和它相关的词
- 多头注意力：同时从语法、语义等多个角度听

## 大模型的三个养成阶段

![图 3-2 LLM 训练三阶段流程图（Pre-training → SFT → RLHF）](images/fig3-2.jpg)
- **预训练**：读遍海量文本，练习“接龙”——背菜谱
- **监督微调**：用几万条问答示范，学会按要求回答——大厨带徒弟
- **人类反馈强化学习**：人给回答排序，学会更有用、更安全——顾客打分

## 动画：温度与采样

!sim temperature-sampling
- 大模型按概率“抽”下一个字
- 温度低：稳定、保守；温度高：多样、跑偏
- 写通知用低温度，写诗可以高一点

# 3.5 提示词工程：自然语言编程

## CO-STAR 法则

![图 3-7 CO-STAR 框架六要素图解](images/fig3-7.jpg)
- **C** 背景 · **O** 目标 · **S** 风格
- **T** 语气 · **A** 受众 · **R** 回复格式
- 不必每次六个都写，缺什么补什么

## 动画：提示词改写前后

!sim prompt-rewrite
- 从“小白写法”开始，逐个勾选六要素
- 看输出哪里变好了
- 对照下方的检查清单

## 两个进阶锦囊

- **少样本提示**：先给两三个例子，AI 照着格式做
- **思维链**：“请一步一步地分析”，复杂问题更准
- 让 AI 先提问：“写之前，你还需要知道什么？”

# 3.6 从聊天到行动：RAG 与智能体

## RAG：开卷考试

![图 3-8 RAG 流程图：用户提问 → 向量检索 → 上下文增强 → LLM 生成](images/fig3-8.jpg)
- 闭卷：只凭记忆，容易编造
- 开卷：先**检索**资料，再**看着资料回答**
- 能回答私有的、最新的信息，还能给出处

## 动画：RAG 开卷考试

!sim rag-open-book
- 比较闭卷和开卷的回答
- 看检索出的前 3 段资料
- 勾掉一段资料再问——资料缺了，回答就错了

## 智能体：不只说，还要做

![图 3-9 Agent 做事的逻辑：感知 → 规划 → 行动 → 反馈](images/fig3-9.jpg)
- 感知 → 规划 → 行动 → 反馈
- 会调用搜索、计算器、日历等工具

# 3.7～3.8 实战与风险

## 人机协作三个实战

- **读论文**：让 AI 总结、解释术语、出题考自己
- **写小说**：AI 帮你搭大纲、改文笔，故事是你的
- **做小游戏**：用自然语言描述，AI 写代码，你来测试
- 原则：AI 当“陪练”和“助手”，不当“代写”

## 四类风险

| 风险 | 表现 | 怎么办 |
|---|---|---|
| 幻觉 | 编造论文、数据、法条 | 核实原始出处，用 RAG |
| 越狱与注入 | 被诱导说出不该说的 | 重要操作人来确认 |
| 偏见 | 放大数据中的刻板印象 | 多角度提问，保持怀疑 |
| 数据泄露 | 敏感信息被保存或泄露 | 不输入隐私和保密资料 |
