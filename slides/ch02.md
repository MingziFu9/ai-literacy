## 一张照片，机器怎样认出是猫？

- 人：一眼就认出来，说不清为什么

# 2.1 神经网络：非生物的“大脑”

## 2012 年：AlexNet 一战成名

![图 2-1 AlexNet 架构与第一层卷积核可视化](images/fig2-1.jpg)
- ImageNet 竞赛：1000 类、上百万张图片
- AlexNet 错误率 15.3%，比第二名低近 11 个百分点
- 三个关键：GPU、海量数据、更深的网络
- 第三次 AI 浪潮由此开始

## 动画：神经元与激活函数

!sim neuron-activation
- 输入 × 权重，加起来，再过激活函数
- 调权重，看输出怎样变化
- 神经网络 = 很多这样的神经元一层层连起来

## 反向传播：一场“追责风暴”

- 预测错了，算出错多少（损失）
- 从输出层往回追：每个权重该负多少责？
- 每个权重往“减小错误”的方向挪一小步（梯度下降）
- 重复几百万次，网络就学会了

![图 2-2 梯度下降算法在损失地形上的不同路径](images/fig2-2.jpg)

::: notes
可以用“公司出了质量事故，从总经理一级级往下追责”打比方。线下课的角色扮演就演这个过程。
:::

## 过拟合：AI 变成“复读机”

![图 2-3 过拟合曲线](images/fig2-3.jpg)
- 训练题全对，新题一塌糊涂——“背题”
- 训练误差一直降，测试误差先降后升
- 对策：更多数据、Dropout、早停、数据增广

## 中国力量：百度飞桨

- 2016 年开源，国内首个产业级深度学习平台
- PaddleOCR、PaddleDetection、PaddleNLP 等组件
- 支持部署到国产芯片
- 自主可控的 AI 基础设施

# 2.2 深度推理：快思考与慢思考

## 系统 1 与系统 2

![图 2-4 从 System 1 到 System 2：AI 推理范式的跃迁](images/fig2-4.jpg)
- **系统 1（快思考）**：凭直觉，一口气说出答案
- **系统 2（慢思考）**：一步步推理，边想边检查
- 普通大模型像系统 1，推理模型学会了系统 2

## 动画：快思考与慢思考

!sim fast-slow-thinking
- 9.11 和 9.9 哪个大？“strawberry”里有几个 r？
- 比较直接回答和先推理再回答
- 慢思考的代价：更慢、更多词元

## DeepSeek-R1 的三大突破

| 突破 | 一句话 |
|---|---|
| “顿悟时刻” | 没人教它自我检查，强化学习中自己学会了 |
| GRPO | 用规则自动判分（答案对不对、格式对不对）做奖励 |
| 蒸馏 | 把大模型的推理能力“教”给能在电脑上跑的小模型 |

::: notes
R1 的思维链是显式输出的，能在 DeepSeek 打开“深度思考”看到。成本方面，“几百万美元”只是最后一次训练的算力租金估算，不含研发和试错。
:::

## 什么时候该打开“深度思考”？

![图 2-6 推理时长 vs 任务复杂度：两种 AI 的分界线（示意）](images/fig2-6.jpg)
- 数学、逻辑、多步分析：打开
- 查常识、改错字、闲聊：没必要
- 推理模型也会想错，结论仍要核实

# 2.3 Transformer：大模型时代的架构

## 2017 年：“注意力就是你所需要的一切”

![图 2-8 Transformer 完整架构（Encoder-Decoder 结构）](images/fig2-8.jpg)
- 谷歌 8 位研究员的论文
- 抛弃逐词处理的 RNN，所有词同时处理
- 可以并行，适合 GPU，模型可以做得很大

## 注意力：每个词都看所有词

![图 2-7 自注意力机制让 AI“看到”词与词之间的关系](images/fig2-7.jpg)
- “小猫追老鼠，它跑累了”——“它”指谁？
- 注意力给相关的词更高的权重
- 多头注意力：从多个角度同时看

## 动画：自注意力

!sim self-attention
- 点一个词，看它在“注意”哪些词
- 体会“它”怎样找到指代对象
- 掩码：写作时只能看前文

## 两大流派与缩放法则

| | BERT | GPT |
|---|---|---|
| 擅长 | 理解（分类、检索） | 生成（写作、对话） |
| 结构 | 编码器 | 解码器 |
| 训练方式 | 完形填空 | 预测下一个词 |

::: notes
缩放法则：参数和数据要匹配（Chinchilla 定律），还可以让模型在回答时“多想一会儿”，这就是推理模型的思路。
:::

## 本章小结

- 神经网络 = 多层神经元 + 反向传播 + 梯度下降
- 过拟合是“背题”，要用新数据检验
- 推理模型学会了“慢思考”，但也会想错
- Transformer 用注意力让每个词看到所有词
- 算法、算力、数据共同推动了 70 年的进步
